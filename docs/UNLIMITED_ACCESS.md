# Бессрочный доступ

Новые профили WireGuard, публичного OpenVPN и Telegram/MTProto создаются с `expires=0`, `unlimited=true`. Параметр `TRIAL_HOURS` больше не задаёт срок; совместимое поле `hours` в API равно нулю. Автоматический отзыв по времени для таких профилей не выполняется. Смена сервера, пауза Telegram и ручной отзыв остаются доступны.

Миграция `permanent-access-v1` переводит существующие активные/создаваемые профили в бессрочные, сохраняя ID и ключи. Управляемые узлы получают повторное применение того же доступа. Отозванная и истёкшая история не восстанавливается.

WireGuard-контроллер принимает срок `0` и сохраняет `unlimited=true`; отзыв записывается отдельным флагом, чтобы сбой сохранения не восстанавливал отключённого клиента. MTProto включает бессрочные секреты в желаемое и фактическое состояние транспорта. Локальные помощники запуска обновляют код собственных контейнеров. Для удалённых WireGuard-узлов перед применением требуется обновить `deploy/node_control.py` на узле.

Технические таймауты сетевых запросов, срок Telegram-авторизации и короткие ссылки передачи конфигов не являются ограничением длительности VPN и сохраняются.

Бот использует короткие HTML-сообщения, три ряда основных действий в профиле и компактную клавиатуру 3×4. Старые текстовые кнопки и callback-команды продолжают обрабатываться.
