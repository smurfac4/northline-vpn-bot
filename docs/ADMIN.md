# Администрирование

Доступ к `/admin` разрешён только Telegram ID из `ADMIN_TELEGRAM_IDS`. Открывайте панель командой `/admin` в боте. Авторизация проверяется на сервере по подписанным данным Telegram; локального входа без авторизации нет.

Панель показывает реальные серверы, аккаунты, профили и обращения. В ней можно добавлять собственные серверы, менять обслуживание, разрешать пользователю каждый из двух типов подключения отдельно и отзывать профили. Индивидуальные разрешения сохраняются в SQLite; общий список задаёт `ALLOWED_TELEGRAM_IDS`.

Публичные серверы обновляются автоматически каждый час. Известные неработающие записи скрываются из выбора; ссылки и файлы для них больше не выдаются. Профиль предлагает проверенную замену той же страны, если она нашлась. После смены нужно обновить подключение на устройстве.

Скорость собственных узлов — текущий трафик между двумя замерами, а не максимальная пропускная способность. Для публичного MTProto проверяется ответ Telegram, для OpenVPN — туннель и HTTPS через него. Счётчики чужих серверов недоступны. Выдуманных показателей нет.

Изменение адреса, ключей или удаление собственного сервера с текущими профилями блокируется до их отзыва. При сохранении реестра создаётся закрытая резервная копия. Редактор передаёт версию реестра, чтобы параллельные изменения не перезаписывались.

В настройках доступен управляемый перезапуск бота и Mini App. Проект должен быть запущен через `run.py`. Профили, ключи и настройки сохраняются при перезапуске.

Журнал хранит до 30 000 обращений за 14 дней. Токены, ключи и конфиги в него не записываются. Для переноса сохраняйте базу вместе с реестрами и `.env`; для новой установки используйте [чистый комплект](HOSTING.md).
